# Dossier des données

Place ici les deux fichiers du jeu Sparkov (Kaggle : `kartik2112/fraud-detection`) :

- `fraudTrain.csv`
- `fraudTest.csv`

Puis lance `python train.py` (à la racine du projet).

Le sous-dossier `demo/` contient des données SIMULÉES (créées par `python train.py --demo`) uniquement pour tester l'import de fichier dans l'application.
